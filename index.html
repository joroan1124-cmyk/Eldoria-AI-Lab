How your data is used

If you enable Gemini through your Worker, source code and diagnostics you submit are sent to Google's API for analysis. Google's documented free tier may use submitted content to improve products. Use only code you are comfortable sending to that provider. Keep billing disabled; the Worker permits only the listed free-tier model IDs and never upgrades to a paid model automatically. Free quotas can change, and quota exhaustion stops AI suggestions rather than switching providers.
